🔐 SecurePassX – Password Strength Tester Tool

SecurePassX is a simple and powerful password strength testing tool built for cybersecurity students and beginners.
It helps users evaluate how strong or weak a password is based on multiple security rules.

This project is perfect for learning about:

Password security

Common password weaknesses

Strength scoring systems

Cybersecurity best practices

🚀 Features

✅ Checks password length
✅ Detects uppercase and lowercase letters
✅ Detects numbers and special characters
✅ Identifies weak/common passwords
✅ Provides strength score (Weak / Medium / Strong)
✅ Gives improvement suggestions

🛠️ Technologies Used

Python 3

Regex (Regular Expressions)

Basic Security Logic

📊 Strength Rules

SecurePassX evaluates passwords based on:

Rule	Description
Length	Minimum 8 characters
Uppercase	At least 1 capital letter
Lowercase	At least 1 small letter
Numbers	At least 1 digit
Special Characters	At least 1 symbol like @, #, $
🎯 Strength Levels

🔴 Weak (Easy to crack)

🟡 Medium (Needs improvement)

🟢 Strong (Secure password)
